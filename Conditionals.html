01 // MAP

The whole system on one screen

First decide what the sentence means. The form then follows.

0
Zero conditional

Facts, routines, things that are generally true.

if + present → present
WHENEVER this happens, that happens.
1
First conditional

A real / possible future condition and its likely result.

if + present → will + infinitive
JESTLI — I see it as a real possibility.
2
Second conditional

An unreal, unlikely or imagined present/future situation.

if + past → would + infinitive
KDYBY — imagine the situation now.
3
Third conditional

An unreal past: reality is already fixed.

if + past perfect → would have + V3
KDYBY BÝVAL — rewrite the past.
M
Mixed conditionals

Cause and result live in different times.

past cause → present result
present state → past result
MIX TIME, not random grammar.
Core insight: conditionals are not primarily about “number 1, 2, 3”. They encode the speaker’s view of reality / probability and the time of the condition and result.
02 // TIME + REALITY

Put the meaning on a timeline

This is the fastest way to separate second, third and mixed conditionals.

PAST
finished reality
NOW
current state
FUTURE
possible / imagined
SECOND CONDITIONAL

If I had more time, I would exercise more.

Condition = unreal now. Result = imagined now / future.

THIRD CONDITIONAL

If I had had more time, I would have exercised more.

Condition = unreal past. Result = unreal past.

03 // DIAGNOSTIC

Can you see the meaning?

Do not calculate the tense first. Ask: fact, real possibility, unreal now, unreal past, or mixed time?

0/8checked
04 // CONTRAST

First or second? The speaker chooses.

The difference is often not objective probability. It is how the speaker frames the situation.

REAL / OPEN

If I get the job, I will move to Brno.

I regard getting the job as a genuine possibility.

HYPOTHETICAL / REMOTE

If I got the job, I would move to Brno.

I am imagining it more hypothetically or I think it is unlikely.

0/4correct
05 // FORM BUILDER

Build it accurately

Type the missing verb phrase. Contractions and full forms are both accepted where sensible.

0/10correct
Exam-safe default: in an ordinary first conditional, use a present form after if, not future will. In an ordinary second conditional, do not mechanically put would in the if-clause. Advanced exceptions exist when will / would carries its own meaning such as willingness, insistence or politeness.
06 // MIXED

Mixed conditionals = mixed time

Find the time of the cause and the time of the consequence. Then combine the familiar patterns.

PAST CAUSE → PRESENT RESULT
if + past perfect → would + infinitive

If I had gone to bed earlier, I wouldn't be so tired now.

I didn't go to bed early then → I am tired now.

PRESENT STATE → PAST RESULT
if + past → would have + V3

If I were more organised, I wouldn't have missed the deadline yesterday.

I am not organised in general / now → I missed it then.

0/4correct

08 // PRECISION

Small details that raise your accuracy

These are useful for Maturita writing and speaking, but the core conditional meaning stays the same.

Unless

unless = if … not. “Unless you hurry, you'll miss it.” Avoid a second negative.

Were

For hypothetical be, If I were you… is the safest formal/exam choice.

Modal results

Results can use may, might, could, can where the meaning fits — not only will/would.

Comma

If the if-clause comes first, use a comma. If it comes second, a comma is usually unnecessary.

Stronger class extension: contrast “If you will wait here…” (willingness/polite request) with ordinary future conditionals. Keep this as nuance, not the first rule students remember.
09 // MATURITA SPEAKING

From grammar to actual communication

Work in pairs. One student answers; the partner must ask one follow-up question containing another conditional.

Scenario A · choices

Your school offers you a six-month exchange abroad.

What will you do if you are accepted? What would you do if the destination were somewhere you did not expect?

Support: If I get accepted, I’ll… / If the destination were…, I’d… / Unless…, I probably wouldn’t…
Scenario B · regrets

Think of a decision you made in the last two years.

How would things have been different if you had chosen differently? Is there any effect on your life now?

Support: If I had…, I would have… / If I had…, I would be… now.
Scenario C · society

Imagine one major change in education, transport, technology or the environment.

What would happen if the change were introduced? What happens when people ignore the problem?

Support: If schools introduced…, students would… / If people ignore…, … happens.

11 // DIFFERENTIATION

Two routes through the same lesson

Use this if students finish at different speeds.

SUPPORT ROUTE

For students who still hesitate

Keep the five-card map visible. Before every answer, say the meaning aloud: fact / real future / unreal now / unreal past / mixed time. Then choose the form.

Minimum target: 0–3 conditionals accurate; recognise the two mixed patterns with support.

CHALLENGE ROUTE

For students who are already secure

Rewrite answers using unless, modal results, inversion (Had I known…) or more nuanced probability. Explain how changing 1st → 2nd changes the speaker’s stance.

Stretch target: manipulate conditionals deliberately for style and nuance.
